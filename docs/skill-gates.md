# Skill gates: side quests and games you unlock by learning

Consoles QUESTMASTER, QUESTMASTER-2 and QUESTMASTER-3 (`tools/briefs/frontier-brief.md`, `tools/briefs/next/questmaster-next.md`, `tools/briefs/next/questmaster-2-next.md`). A quest, side game, treasure or egg can carry a **gate**: it stays locked until the learner has finished the named training. A locked item is still shown on maps and boards, with a padlock, the reason and a link to each required station. Treasures are the only items that stay hidden, because finding them is the point. A gate is never used to hide something.

## The contract

```js
gate: {
  stations?:   ["crane-yard", ...],                // complete at 1+ star in the attempt log
  programmes?: [{ id: "hotel-workers", minStars?: 4 }],  // every station done, or best stars summed >= minStars
  quests?:     ["bw-main-02-yard", ...],           // Bay World quest, a Deep dive, or a clean side-game run
  k12?:        ["k12-reading-a-map-scale-in-bay-world"],  // a classroom programme station, 1+ star
  note: "Crane yard and dock crane stations before you take a night-shift lift."
}
```

- `WebXR/shared/skill-gates.js` is the engine. It uses no DOM and its storage can be injected.
  - `qmSnapshot()` reads the attempt log (`vr-training-records-v1`), the quest stores (`bayworld-quests-v1`, `underwater-dives-v1`) and the side-game ledger (`qm-side-games-v1`, which is stored per profile).
  - `qmIsOpen(gate, snap)` and `qmMissing(gate, snap)` answer the gate. `qmMissing` returns rows ready to display.
  - `qmSkillsToUnlock(items, snap)` builds the "Skills to unlock" roll-up.
  - `qmFinishGame(game, { score, of })` records a run.
  - `qmCachedSnapshot()` re-reads at most once a second, for per-frame callers.
- `WebXR/shared/skill-gates-ui.js` is the lock UI:
  - `qmMountSideGames()` adds the "Side games" chip in the shared nav and opens the quest-log panel. The panel lists open rows, then locked rows, then **Skills to unlock** and the cosmetics earned.
  - `qmBoardRows()` adds rows to a job board.
  - `qmLockToast()` shows the lock reason with links to the required stations.
  - `qmDrawPin()` draws a map pin: a padlock while locked, a star once open.
  - `qmBoardRows(el, items, opts)` takes `heading`, `done(id)` (a world engine's own completion) and `link` (extra `lkStationLink` options such as `siteId`).
- `WebXR/shared/side-game-mechanics.js` holds the twelve playable mechanics (below). `WebXR/shared/side-game-stage.js` draws a mechanic's board **in the world** (meshes at the item's place, the moves in a HUD strip) and runs the same steps as the panel; `WebXR/shared/side-game-cosmetics.js` puts the cosmetics earned on the avatar; `WebXR/shared/k12-gates-data.js` exports the K-12 courses (`K2_GATED`). `WebXR/shared/gate-names-data.js` (generated by `tools/gen_gate_names.mjs` from the catalog) gives every gated station its display name; `qmLabel(id)` reads it.
- **Bay World hook.** `bayworld/js/quest-engine.js` has one line in each advance loop: `if (quest.gate && !qmIsOpen(...)) continue;`. That is the only gate logic in the engine, so the change that makes the engine honour `requires` merges beside it cleanly.

Examples:
- The night-shift crane puzzle is opened by the crane yard and dock crane stations.
- The harbour salvage hunt is opened by the dive supervisor and lift-bag rigging stations.
- The timed-but-safe delivery run is opened by the pre-trip and air-brake test stations plus the Yard Qualified quest.
- The grid restoration puzzle is opened by the line truck and substation switching stations.
- The kitchen rush is opened by the kitchen, knife skills and allergen control stations.
- The regatta rescue drill is opened by the overboard recovery and cold-water immersion stations.
- Two items use K-12 gates, a map-scale course and a buoyancy trim course.

**Scoring and rewards.** Every item is scored only on safe practice. A round is one prompt with a safe call and an unsafe call. The prompts come from `QM_SAFE_PRACTICES`, which holds generic habits phrased "per the plan / label / dive plan" and contains no numbers. Only a run in which every call is safe marks the item done and unlocks its one cosmetic avatar item. A run with an unsafe call counts as practice. Nothing can be bought, nothing is random and nothing scores harm.

## Playable mechanics (12)

`WebXR/shared/side-game-mechanics.js`. Every item plays one mechanic before its safe-practice calls, as one run with one score; a clean run is every move and call safe. Each mechanic is a pure step generator: a step shows a **board** (a few lines of text drawing the situation) and two moves, exactly one of them safe. Nothing is scored on speed or harm — the overboard drill shows a spotter counting aloud and never scores the count. `qmMechanicFor(item)` picks by `item.mechanic`, else the first `match` that fits the title or id (the order of `QM_MECHANICS` is the priority), else the inspection grid.

| Mechanic | The move | Fits |
|---|---|---|
| Lift sequencer | order the picks so no load passes over a person | crane, salvage, rigging, load-in |
| Switching order | a read-back on every step of the switching order | grid, substation, labels, solar |
| Inspection grid | check every piece on the rack; tag out what is damaged | lashing, pilings, mower pre-start, greens |
| Line follow | knot by knot with a buddy check at each | night line, transect, tether, trim |
| Overboard drill | alarm, spotter, approach, recovery | rescue, cold water |
| Delivery run | the plan's route, on time only when safe | delivery, docking, tow, transfer, brakes |
| Kitchen rush | clear the ticket rail without an unsafe plate | kitchen, banquet |
| Traffic zone | signs, taper, spotter, in the plan's order | traffic, storm, work zone, water main |
| Lockout steps | notify, isolate, lock, verify, then reach in | lockout, leak, jam, confined space |
| Survey transect | log every point from the line; flag, never pull | map, count, survey, marking, sensors |
| Spill response | stop the flow, contain it, report it | fuel, chemical |
| Lookout watch | report by the form, keep the radio, name the way out | lookout, patrol, night watch |

## Mechanics in the world

`WebXR/shared/side-game-stage.js`. The mechanics stay pure; the stage renders a step's board with meshes at the item's place and rebuilds it for every step, while a HUD strip (`#qm-stage`) carries the prompt and the two moves. The run is a pure state machine (`qmStageRun`) over `qmPlaySteps`, the same list the panel plays, so the world scores exactly what the panel scores, and both end in `qmFinishGame`. The 3D library is taken from the caller (`lib`), so the module never names it (the bundler would otherwise load it for every page).

| Mechanic | Drawn as | Where |
|---|---|---|
| Lift sequencer | three marked loads, the hook over the current pick, the landing pad, the crew on the walkway the board names and the safe swing path as an arc of markers | Bay World's rigging quay (an open gated quest's anchor) |
| Line follow | the line out from the reel with three knots as lights, the current one bright, the buddy and lamp behind, silt on the middle step | the Deep's night line site |
| Traffic zone | the cart path beside two held carts, advance signs, the cone taper and the spotter with a horn, each placed once its step is done and ghosted while it is next | Fairway's cart path (the storm-cleanup pin) |
| every other mechanic | a marker row with the current step raised and lit | wherever the item sits |

A world mounts the stage when the learner walks, swims or plays up to an open item's place (`qmStageMount({ lib, root, item, at, heading, onDone })`); a locked item still toasts the lock, and a finished one says so. The checker builds each of the three boards with a stub library, asserts the traffic board changes between steps, and proves an all-safe stage run is clean while one unsafe move is a practice run.

## Cosmetics on the avatar

`WebXR/shared/side-game-cosmetics.js`. The ledger's cosmetic ids map to a slot by their words (a helmet decal, cap or beanie to the **head**; a wristband, bracelet or gloves to the **wrist**; a fin tag, ribbon or waders to the **fin**; everything else a **shoulder** patch) and to a colour from a hash of the id, so a cosmetic looks the same in every world. Bay World dresses its person figure (`qmDressFromLedger(lib, world.player, "person")`) and the Deep its diver (`"diver"`), at load and again after a clean run. Nothing is bought; there are no textures or assets.

## Adding gated items from another console

Export an array whose name contains `GATED` from a `*-data.js` module under `WebXR/`. The module must not import from a CDN. Each item needs at least `{ id, world, title, gate, practices, reward: { cosmetic } }`. `tools/check_gates.mjs` discovers the module and checks each item. To show the items, mount `qmMountSideGames({ world, items, from, page })` on the world page and add the three modules to that world's bundle.

## The checker

`node tools/check_gates.mjs` is part of `check_all`. It checks that:
- every gate id resolves (stations, K-12 stations, programmes, quests) and that each station link routes to a page that exists;
- every item has a note, and the note contains no digit;
- a fresh profile sees every item locked, the exact required completions open it, and removing one required station locks it again;
- scoring, rewards and wording follow the rules above;
- the side-game ledger behaves correctly and is stored per profile;
- the quest-engine hook stops a locked quest from advancing and lets an open one advance;
- each of the six worlds mounts the lock UI, draws pins and rows and toasts where it has a map or a board, and each bundle carries the modules in load order;
- every gated station has a display name (`node tools/gen_gate_names.mjs`), every Regatta game sits on a real course and mark, every `requires` chain resolves;
- the twelve mechanics: every item resolves to one, every mechanic is used, each step has exactly one safe move and a deterministic, digit-free board, and a clean run is the only run marked done;
- the stage: a 3D builder for the lift sequencer, the line follow and the traffic zone (built with a stub library), run parity with the panel, the three worlds mount it and bundle it;
- cosmetics: every reward id lands in a slot, dressing adds one decal per id and replaces the last set, Bay World and the Deep dress their avatars;
- K-12: `K2_GATED` discovered with 5+ items, each opened by its field lesson's station, listed by Bay World and the Deep;
- the bar: 70+ items across 6+ worlds, every item placed in a world, gated items discovered from other consoles' modules.
