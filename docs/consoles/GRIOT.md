Pack lines are copied verbatim from a source and carry the pointer: `{ kb: chunkId }` (a sentence of a Guide KB chunk), `{ union: id }` (the registry note), `{ standard: id }` (a verified standard's title), `{ station: id }` (the catalog tagline).   2. **Engine, pure.** `WebXR/shared/npc.js`: `grDialogue(ch, { question, seed })` → greet (a template naming role and site, no fact), teach one pack line with its source (chosen by a small BM25 over the pack when a question is asked, else by seed), hand off (one of the character's hand-offs, resolved through `links.js`); `grAgentAdapter(ch)` in the `agent-protocols.js` shape (fields `endpoint`, `model`; `respond()` refuses with "configure per the provider's current documentation" while unset and never sends; a hosted reply is only spoken if it is one of the pack's own lines verbatim, otherwise the on-device line speaks).
  3. **Figures and routines.** `grBuildFigure(three, ch)` = `ctAvatarFigure`; `grMount(world, hooks)` places each character of that world at its site (`hooks.sites`, `hooks.groundAt`), runs work → walk → break → walk loops by property writes, animates only within 150 m of `hooks.pos()`, hides beyond 600 m; `near(x, z)` within 4 m; a `G` key / touch "Talk" button opens a small panel with the three moves and an Ask box; keys inside the panel never reach the world.
  4. **Placement rule.** Routine points sit 7–13 m from the site centre on the east, west or north side, never in the south corridor where every world's board (z + 6 / pad × 0.5) and arrival spot (z + 16 / pad × 0.75) sit — so no character blocks a door, a board or a pad.
  5. **Mounts.** Bay World (`bwStep`), Summit (`frame`), Redwood (the frame) call `grMount` with their sites, ground and player position; the parishes call the same hook when PARISH lands (`grMount("parish:<id>", { sites })` matches roster entries by `site.kind`).
