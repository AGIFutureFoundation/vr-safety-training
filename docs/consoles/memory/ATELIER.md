# ATELIER memory — what the next ATELIER session needs to know

- **One source per layer.** Tokens live in `WebXR/shared/theme.js` (`AT_ROLES` maps onto POLISH's `TH_TOKENS`); components in `tools/gen_design.mjs`; illustrations in `WebXR/shared/illustrations.js`; icons are the SVG files in `WebXR/vendor/icons/`. `WebXR/shared/design.css` and `WebXR/design/index.html` are generated — run `node tools/gen_design.mjs`, then `python3 tools/bundle_webxr.py`. `check_design` fails on a stale copy.
- **Adding an icon:** `npm pack lucide-static@1.48.0` into the scratchpad, copy the one SVG into `WebXR/vendor/icons/`, regenerate design.css and `docs/credits.md` (every vendored filename must appear there in backticks), then use `<span class="at-i at-i--name" aria-hidden="true">` or `data-at-icon="name"` (the latter survives code that sets `textContent`, like the i18n layer and the egg buttons).
- **Link paths:** source pages link `../shared/design.css` (homepage `./shared/design.css`); `dist_fixup` makes it `../../` for `WebXR/<app>/dist/`, `combined_fixup` makes it `./shared/design.css` in `WebXR/dist/`, and the flat folder gets copies of the stylesheet, `vendor/fonts/`, `vendor/icons/` and the gallery. Track pages are written for `WebXR/dist/tracks/` (`../shared/design.css`).
- **Page palettes alias the roles** (`--panel:var(--at-surface, #old)`) on the homepage, track pages, Atlas and instructor console — keep the fallback so a page opened without the stylesheet still paints.
- **The Home glyph** is gone from markup and all 21 `tools/i18n/*.json` tables; the house icon is `.home-chip::before` in design.css. Do not put a glyph back in `nav.home`.
- **Gotchas met:** inline SVG must not carry `xmlns` (check_tracks rejects any absolute URL on track pages); ◀ ▶ are Extended_Pictographic, so `check_design` counts them as emoji; React children as arrays need keys — use `h(Fragment, null, icon, " text")`.
- **Boundaries:** CINEMA owns the background `<video>` and `WebXR/home/media/backgrounds.json`; WAYFINDER owns headings, meta/SEO, navigation and header structure. The fixed chip bar overlapping the brandline on track pages is a header-structure finding handed to WAYFINDER, not fixed here.
- **Captures:** `node tools/capture_atelier.mjs after` (and `ATELIER_DIST=<old dist> … before`) picks the first free 89xx port, never 8970/8971.
