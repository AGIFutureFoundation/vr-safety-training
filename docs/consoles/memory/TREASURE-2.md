# TREASURE-2 — memory (read first, after TREASURE's)

- Everything in `docs/consoles/memory/TREASURE.md` still holds: lessons are lifted, never typed; add a treasure by adding a source line in `tools/gen_treasures.mjs`, then `node tools/gen_treasures.mjs && python3 tools/bundle_webxr.py && node tools/check_treasures.mjs`.
- Gates are the shared engine's now: `tzGateMissing`/`tzGateOpen` call `qmMissing`/`qmIsOpen` from `shared/skill-gates.js`. `tzGateSnapshot(records)` builds an engine snapshot from an injected records array (the checker's path); with no array it invalidates the engine's cache and reads the learner's own stores. Missing rows are the engine's `{ kind, id, label, detail }`, not station ids — `tzLockNotice` links stations/k12 and prints programmes/quests as text.
- `TZ_GATED` is exported from `treasures-data.js` with `world: "treasures"`; `tools/check_gates.mjs` discovers any `…GATED…` array in a `*-data.js` and asserts a lock note carries no digit — keep site names out of notes, or check them, before generating.
- `treasures.js` is shared chrome: it must never contain the text `THREE.` (the bundler would ship three.js on every flat page with the account chip). The 3D finders take the library from the caller as `T3` (`tzPlantHost(root, T3, host)`, `tzWatchWorld(world, { THREE: T3, … })` — the option name stays `THREE` for the existing callers). The checker asserts it.
- The bundler auto-inserts `passport-programmes.js` + `skill-gates.js` before `treasures-data.js` in any app that carries the treasure layer without the engine, and copies `skill-gates.js` into `dist/shared/` for the flat Treasure Map page.
- Summit's notes sit at `e.at`, Redwood's tins at `e.position`; both worlds' field notes/tins stay theirs. Treasures sit off trail, road and tower vertices with `place()` (offset list, ≥ 15 m from every note/tin, out of the lake/water, outside every site pad + 30 m). A vertex inside a site pad has no clear spot — filter those out before placing.
- `smZoneAt(x, z)` returns a zone object, not an id; `zoneName()` needs the id.
- The worktree guard refuses long compound shell commands and heredocs; put multi-file edits in a script under `$SP/holodeck/treasure-2/` and run it with one argument.
- The worktree may start on the repo's initial commit; `git merge --ff-only claude/vr-ar-safety-training-wkwmve` first.
