# ATELIER-2 memory — what the next ATELIER session needs to know

Everything in `docs/consoles/memory/ATELIER.md` still holds. Added this run:

- **Start from the right head.** A fresh worktree may sit on the two-month-old `main`; `git reset --hard claude/vr-ar-safety-training-wkwmve` before reading anything. The sandbox refuses shell loops and heredocs that name git or compute a command's operand: write the script to the scratchpad and run it as one plain command (`python3 <file>`, `node <file>`).
- **World pages keep their accent.** Summit and Redwood alias the neutral roles (`bg`, `surface`, `raised`, `on-surface*`, `border*`), the type roles and the shape roles, but keep their own accent hues, so the design system reads as one family without every world turning cyan. The same rule applies to the Treasure Map's gold.
- **Icons without markup changes.** A class an app's script sets (`.lock`, `.done`, `.empty`) can carry an icon from CSS: `::before` with `background:currentColor; mask:var(--at-icon-<name>) center/contain no-repeat`. The `--at-icon-*` variables live on `:root` in design.css, so any page that links it can use them.
- **Illustration rules match segments.** `AT_ILLO_RULES` keywords must not match inside a word (`port` matched `support`); anchor with `(^|-)word(-|$)` when a keyword is short. Specific kinds go before their family (`k12-science` before `k12`). 21 kinds; the gallery and `check_design` pick new kinds up from `AT_ILLO_KINDS` automatically, but `gen_home` and `gen_tracks` must be re-run for the cards and heroes to change, then the bundler.
- **Chip-bar clearance.** The fixed Home / help / sign-in / language bar is `#ctl-nav` (`shared/controls.js`); a page with a top band pads by a CSS variable measured from `#ctl-nav.getBoundingClientRect().right + 12` (homepage `--hm-nav-w`, tracks `--at-nav-w`); a plain page (instructor console) needs about 60 px of top padding.
- **Merging ENTERPRISE.** `guide-kb.js` conflicts and `gen_guide_kb` refuses at 641 KB against its 640 KB cap once `docs/enterprise.md` is indexed; the investor files regenerate with `node tools/gen_investor.mjs`. `check_links`' `LK_DOC_PAGES` must keep both `404.html` and `privacy.html`.
- **Captures:** `ATELIER_PORT=8999 node tools/capture_atelier.mjs after`, `ATELIER_SHOTS=summit,cohorts` to narrow; ten shots at two sizes take about three minutes on the shared machine.
