# HARVEST memory

- Module `WebXR/shared/hv-harvest.js` (data + pure logic + `hvMount`), checker `tools/check_harvest.mjs` (`--live` adds one
  headless Orleans load on port 9005), docs `docs/consoles/HARVEST.md`.
- Mounted once in `WebXR/parishes/js/app.js` into `menu-harvest` (Play tab), `window.__parishTest.harvest`; bundled for
  the parishes app right before app.js (after account.js, which brings treasures.js).
- 94 procedural spots on 20 of 22 maps (sf-haight-castro and bay-san-jose have no fishable water by the class rules).
  Activities: fish, crab, shrimp, oyster survey, gator watch / adult gator season, crawfish, rice.
- Treasures: `how: "harvest"`, `tz-harvest-<activity>`, set `harvest-hands`, generated by `tools/gen_treasures.mjs`
  from `HV_TREASURE_LINES`; `tzHarvestRun(activity)` in treasures.js.
- Facts: no regulation, season, limit, size or date anywhere; the play calendar is a game cycle (one play season per
  TYCOON week). Adult gate: signed-in account + not the K-12 path + the learner's own confirmation.
