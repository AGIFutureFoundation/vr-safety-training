# TREASURE-3 — memory (read first, after TREASURE's and TREASURE-2's)

- Lessons are themed, not pooled: `siteLesson(site, re)` in `tools/gen_treasures.mjs` takes the site's own unused station why, then `programmeWhy()` (an unused why from one of the site's programmes), and throws if none is left. A place with no station (a Trade Skills room, a racing course) is mapped in `ROOM_WHY` / `TRACK_WHY` by station id; `namedWhy(id)` throws if the table names a station already claimed. Order of generation matters: the runner's tools (`pickWhy`) run before the race, so a table station a tool regex could grab makes the generator throw — pick another.
- Every placed station lesson carries `place: { id, stations }`; the generator and `check_treasures.mjs` both assert the lesson station's programme is one of the place's. Bay and Deep sites use the same `siteLesson()`; their gates use `L.own` (the site's own station) so a programme-fallback why never gates a cache.
- Field-lesson treasures are `how: "lesson"`, `trigger: { world, lesson }`, no x/z — filter marker loops by `how === "proximity"` before measuring distances. Summit lessons have `trade` (their trade line) and `check.choices`; Redwood lessons have `tradeLine` and `check.options`. The four K2 worlds (Bay, Deep, Regatta, Fairway) show `K2_FIELD_LESSONS` only as map rows with a link — there is no in-world check-question flow to hook, so they have no lesson treasures yet.
- `tzLessonAnswered(lessonId)` is the only lesson entry point; Summit calls it in `smOpenLesson` when `smAnswerLesson().ok`, Redwood in `rwRunLesson` on the right option.
- Look-around: `tzWatchWorld` takes `key` (default `TZ_LOOK_KEY` = "KeyL", free in all six worlds) and `near` (90 m); `tzLookAround(world)` lists visible markers within `near` as buttons labelled by distance only. `window.__treasuresTest.lookAround()` calls it in the browser. Headless it returns -1.
- The worktree guard refuses heredocs and long compound commands; write scripts with the Write tool into `$SP/holodeck/treasure-3/` and run `node script.mjs "$PWD"`.
