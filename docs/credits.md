# Credits — vendored assets and their licences

Every third-party file the platform ships from `WebXR/vendor/`, with where it
came from, its version and its licence. `tools/check_design.mjs` (in
`node tools/check_all.mjs`) fails if a vendored file is missing from this page
or a pack's licence file is missing from its folder. Nothing here is a brand,
a logo or a likeness: the icons are generic interface glyphs, the fonts are
open-licence type families, and the programme illustrations
(`WebXR/shared/illustrations.js`) are drawn procedurally in this repository.

The fonts were fetched with `npm pack` and only the woff2 subsets the pages use
were copied; `WebXR/shared/design.css` (generated by `tools/gen_design.mjs`)
declares them with `@font-face` and a `unicode-range` per subset, so no page
depends on fonts.googleapis.com. Scripts Barlow does not cover (Arabic, Urdu,
Devanagari, Bengali, CJK, Amharic and others among the 21 languages) fall back
to the system font stack, as before.
