# Investor data pack

Generated by `node tools/gen_investor.mjs`; checked by `tools/check_investor.mjs`. Every figure is computed from the repository and names its source; nothing is estimated or projected, and no commercial figure is stated.

| File | Rows | What it holds |
|---|---|---|
| [platform-summary.csv](platform-summary.csv) | 49 | Platform-wide counts, each with its source (also as platform-summary.json) |
| [programmes.csv](programmes.csv) | 60 | One row per training programme |
| [stations.csv](stations.csv) | 685 | One row per procedure |
| [assets.csv](assets.csv) | 140 | Every budgeted builder: equipment, vehicles, boats, props, tools, wildlife, sky |
| [vehicles-and-boats.csv](vehicles-and-boats.csv) | 32 | The vehicle and vessel subset with a description from each builder's doc comment |
| [worlds.csv](worlds.csv) | 17 | Open-world scenes and scenic districts |
| [ui-surfaces.csv](ui-surfaces.csv) | 75 | Every built page with its purpose, input modes and HUD panel ids |
| [unions.csv](unions.csv) | 111 | Every union with its training body and the programmes that name it |

Programme overviews: [docs/programmes/](../programmes/README.md).
