# Mapbox brief — the Bay Atlas: real-world maps under the Bay World data

Binds the MAPBOX1 team. The platform ships no secrets: no Mapbox token is ever committed, and nothing contacts Mapbox until a viewer supplies a token.

## Modules
1. `WebXR/shared/bay-geo.js` (pure, no three.js): `BAY_GEO_ANCHORS` — six to eight pairs of a Bay World position and an approximate public longitude/latitude for the public place it is inspired by (a lakeside promenade, a downtown centre, a container port, a stadium district, a hills lookout, a bridge approach; three decimals, marked `approximate: true`, no other fact); `bayToGeo([x, z]) → [lon, lat]` and `geoToBay([lon, lat]) → [x, z]` as a least-squares affine fit over the anchors; `bayGeoBounds()` for the world's lon/lat box. Read `BAY_BOUNDS` from `WebXR/shared/bayworld-data.js`.
2. `WebXR/shared/mapbox.js`: `mapboxToken()` — `?mapbox=` on the launch URL (kept in sessionStorage), then `localStorage["smartciti.mapboxToken"]`, then `mapboxToken` in `auth-config.json` (add the key, null, to `WebXR/auth-config.json` and note it in `docs/sign-in.md`); `loadMapboxGl()` — lazily inserts one `<script>` for `https://cdnjs.cloudflare.com/ajax/libs/mapbox-gl/3.4.0/mapbox-gl.min.js` and injects the library's essential CSS inline (markers, popups, controls; no external stylesheet); `createBayMap(container, { zones, landmarks, sites, onSelect })` — a Mapbox GL map over the Bay with a marker per site and landmark placed by `bay-geo`, zone circles, popups with programme chips; `bayGroundTexture(THREE)` — when a token exists, a Static Images satellite image of `bayGeoBounds()` as a texture for the Bay World ground, otherwise null. Any call without a token returns null without a network request.
3. `WebXR/bayworld/atlas.html` + `WebXR/bayworld/js/atlas.js` — the Bay Atlas page: a site and landmark list with programme chips and deep links (`bayworld.html?site=…`, `../smartcity/dist/smartcity-x.html?sim=…`), a token field ("paste a Mapbox public token; it stays in this browser"), and the map: Mapbox when a token is configured, otherwise an SVG map drawn from the data (zones, roads, sites, landmarks) so the page always works. Register in `tools/bundle_webxr.py` (its module list, output `WebXR/dist/atlas.html`), link it from the home page and from the Bay World HUD's map ("Atlas").
4. In `WebXR/bayworld/js/world.js`, apply `bayGroundTexture` to the ground when it resolves; otherwise the procedural ground stays.

## Checker
`tools/check_mapbox.mjs`, added to `tools/check_all.mjs`: bay-geo anchors round-trip within 1 m; every site and landmark projects inside `bayGeoBounds()`; no string matching a Mapbox token shape (`pk.` followed by base64url) anywhere in the repo; with fetch stubbed and no token, `mapboxToken()` is null and `createBayMap`/`bayGroundTexture` make no request; the atlas page renders headlessly in fallback mode with one marker per site; `WebXR/auth-config.json` carries `mapboxToken: null`; the bundle lists the modules. `docs/mapbox.md`: how to get a token, where to put it, and where it works — the artifact viewer's content policy blocks Mapbox's own hosts, so Mapbox mode works on a self-hosted or GitHub Pages copy and the SVG fallback everywhere.

## Process
Start with `git fetch origin claude/vr-ar-safety-training-wkwmve && git merge --ff-only FETCH_HEAD`. If the network here blocks cdnjs, test the loader by stubbing the script insertion; never vendor the library. Commit in steps; each commit message ends with the two trailer lines given in your task. `python3 tools/bundle_webxr.py` and `node tools/check_all.mjs` must end in the exact "All N checkers pass" line before the hand-back. Hand back within 60 minutes: ≤250 words, commit hashes, the check_all line, what works with and without a token.
