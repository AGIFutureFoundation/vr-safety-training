# Sky brief — skybox, live weather and wildlife for the open worlds

Binds SKY (console SKY). `console-brief.md` and `bayarea-brief.md`'s facts rule apply: wildlife is generic (gulls, pelicans, shorebirds, seals, a fish school, a kelp crab, a ray), never a claim about a real place, a count or a season.

## Deliverables
1. `WebXR/shared/sky.js`: `buildSky(parent, { time, weather })` — a procedural sky dome (vertex-coloured gradient by time band day / dusk / night, a sun or moon disc, a star field at night, a cloud layer whose cover follows `WEATHER[kind].sky` from `WebXR/shared/weather.js`) and `skyFor(time, weather)` returning `{ sky, fog, fogDensity, sunDir, wind: { speed, dir }, visibility }` so the open worlds (`WebXR/shared/bayworld.js`'s `bayLighting`, `fairway.js`, the regatta and the dive game) can read one recipe; `advanceSky(state, dt)` for a slow day cycle and weather drift (clear → overcast → fog → wind → clear) with an event hook. Cheap: a few hundred vertices, property writes only.
2. `WebXR/shared/wildlife.js`: `buildWildlife(parent, { zone, kind, count })` — gull and pelican flocks over water zones, shorebirds on the shoreline, seals on a float, fish schools and a ray under the surface (for the dive game and the outer bay), a kelp crab on rock; each a low-mesh instanced or merged group with a simple motion loop and a `userData.wildlife = { kind }` tag so a game can count a sighting. `WILDLIFE_BUDGET`.
3. Wire it in: Bay World (`WebXR/bayworld/js/world.js`) builds the sky and wildlife for the current zone and drifts the weather; the HUD shows the weather word and wind; Fairway Park uses the same sky. The dive game and regatta read `skyFor` when they exist (do not edit their files if they are absent; leave a documented hook).
4. Gamification: in `tools/gen_bay_quests.mjs`'s authored sections add a "Field Guide" set of eight wildlife-sighting eggs (generic, informative, one line each) and one activity `bw-activity-pier-fishing` (kind `fishing`, catch-and-release at the north pier: rig check, cast with the area clear behind, hook handling, release with wet hands, the licence "per the state's rules" — no size, bag or season figure), regenerate with `node tools/gen_bay_quests.mjs`.
5. `tools/check_sky.mjs` in `check_all`: every time × weather recipe is finite and in range, the dome and wildlife build within budget headlessly, the eggs and activity are present, no numbers in the fishing rules.

## Process
Start with `git fetch origin claude/vr-ar-safety-training-wkwmve && git merge --ff-only FETCH_HEAD`. Keep `docs/consoles/SKY.md`. The bundler concatenates every module into one scope and erases import aliases: prefix top-level names (`sky…`, `SKY_…`, `wl…`, `WILDLIFE_…`). Commit in steps; each commit message ends with the two trailer lines in your task. Gate with `python3 tools/bundle_webxr.py` and `node tools/check_all.mjs` (exact "All N checkers pass" line). Hand back within 45 minutes: ≤250 words, commit hashes, the check_all line, budgets.
