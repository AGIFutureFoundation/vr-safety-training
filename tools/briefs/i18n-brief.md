# Language brief — the whole SmartCiti.X platform in 21 languages

Binds BABEL (console BABEL). `console-brief.md` applies.

## Languages (21)
English, Spanish, French, Arabic, Chinese (Simplified), Russian (the six UN official languages plus English's variants covered by English), Portuguese, Hindi, Bengali, Urdu, Indonesian, Swahili, Hausa, Amharic, Yoruba, Turkish, Vietnamese, Tagalog, Korean, Japanese, German. Arabic and Urdu are right-to-left.

## Build
1. `WebXR/shared/i18n.js` (prefix `tr…`): `trSet(lang)`, `trT(key, vars)`, `trDir()`, a language picker in every page's header beside the Home, help, Guide and account chips (mount it through `controls.js`), the choice remembered (try/catch), `?lang=` on the launch URL, `<html lang dir>` set, RTL layout handled for the header, panels, HUDs and dialogs.
2. `WebXR/shared/i18n-strings.js` generated by `tools/gen_i18n.mjs` from `tools/i18n/en.json` (every UI string in the shared chrome, the homepage, the Guide panel, the account dialog, the help overlay, the job boards, the worlds' HUDs and menus, the station runner's buttons and results screen) and one `tools/i18n/<lang>.json` per language. Write the translations yourself for the UI strings; mark every non-English file `"_review": "machine-assisted, needs native-speaker review"` and say so in the language picker's footnote. Missing keys fall back to English, never to a raw key.
3. Content: translate the **titles and one-line taglines** of every programme and the homepage world cards in all 21 languages (generated tables); station step text stays in English with a visible note ("Step text in English — translation in progress") in non-English modes. The Guide answers in English but its interface and fallback messages follow the chosen language.
4. Wire it in: replace hard-coded strings in the shared chrome and the listed surfaces with `trT()` calls; keep ids and test hooks stable so existing checkers pass.
5. `tools/check_i18n.mjs` in `check_all`: all 21 files have every key or an explicit English fallback marker, placeholders match (`{name}` etc.), RTL pages set `dir="rtl"`, the picker is on every page, switching language changes visible chrome text headlessly at 360 and 1280 without overlap, no untranslated raw keys render.
6. `docs/i18n.md`: how to add a language, how review works.

## Process
Start with `git fetch origin claude/vr-ar-safety-training-wkwmve && git merge --ff-only FETCH_HEAD`. Keep `docs/consoles/BABEL.md`. The bundler concatenates every module into one scope and erases import aliases: prefix new top-level names. Commit in steps; each commit message ends with the two trailer lines in your task. Gate with `python3 tools/bundle_webxr.py` and `node tools/check_all.mjs` (exact "All N checkers pass" line); the machine is shared and slow, so run single checkers while working and the full suite once at the end. Hand back within 55 minutes: ≤200 words, commit hashes, the check_all line, string and language counts.
