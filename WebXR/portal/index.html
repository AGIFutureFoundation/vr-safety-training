VR/AR Training Network

Four independent, self-contained training apps live side by side under WebXR/. Three of them — SmartCiti.X, Trade Skills Simulator and Holodeck — share one procedure engine and one learner profile; Safety Campus is the standalone web companion to the Unity headset build. This page is just a map between them; each app also works fine opened directly at its own URL.

Safety Campus

The standalone WebXR version of the Unity build's hazard-spotting campus: construction, warehouse, fire response, chemical processing, electrical maintenance and the immersive-lab module. Its own scoring, its own progress store — not part of the shared profile below.

Enter Safety Campus

One shared apprentice profile

SmartCiti.X, Trade Skills Simulator and Holodeck's real-station mode all read and write the same learner profile — level, XP, badges and player name carry over between them, because shared/game.js's Progress store is the same module import in all three. A room or station's own record (stars, best score, its own rank ladder) never collides between apps, since every id in the combined 48-profession catalog is unique — only the totals are pooled. Each app's own hub still shows counts scoped to its own catalog (never inflated by a sibling app), so "9/9 rooms" always means this app's nine, not the network's forty-eight.

Safety Campus is intentionally outside this — it is the web mirror of a separate Unity curriculum with its own scoring contract, not a fourth catalog on the shared ladder.

Each app is a fully static page — open any of them directly, or build the single-file versions with python3 tools/bundle_webxr.py from the repository root. Platforms integrate through smartcity/catalog.json (the machine-readable roster with deep links and launch parameters) and the origin-bound smartcitix:* message channel. See the repository README for build/verification details on each.
