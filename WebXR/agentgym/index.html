Watch an agent run a station, then rate it

The stations people train on are also tasks for software agents. These runs were recorded headlessly through the same station engine and scoring you play. The agents are simple baselines: a scripted expert that reads the station's step list, and a word-matching retrieval heuristic. No language model is involved.
