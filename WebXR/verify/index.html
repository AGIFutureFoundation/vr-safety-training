Credential verifier

Paste or drop an Open Badges 2.0 assertion exported from any app in the network (the "Export credentials" file, one assertion or the whole list). The verifier checks its structure, dates, issuer and badge class on this page, with nothing sent anywhere. Where the issuing hall hosts its assertions, it can also fetch the hosted copy and compare.

What a pass means: the file is a well-formed assertion that names a real badge, issuer, recipient and evidence. It does not make the credential a certification — a passing simulator run evidences readiness for the named standard, and the hall that issued it is the authority on whether it counts. Hosted verification confirms the issuer still publishes the same assertion at its own address.
