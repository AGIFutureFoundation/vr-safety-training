    “Send selected” goes to the learner selected on the Live class view; “Send all live” goes to every live session. Both are the same open command the learner's app answers, so the class lands in the station the same way a deep link would.

    Without a relay this console is same-origin and same-device: it uses a browser BroadcastChannel, which does not cross the network. A hall with a row of laptops, or headsets mirrored to one screen, is covered by that alone. To watch from another machine, run node tools/relay_server.mjs and open both the console and each learner's app with ?relay=ws://<host>:8787 — the same JSON envelope then also travels over the WebSocket (see docs/instructor-console.md). When a simulator is embedded in a learning platform, the same events are already sent to the host page, which is the third honest path. Back to the network portal.
